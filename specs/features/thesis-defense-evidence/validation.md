## Bug found and fixed during verification

`src/services/controlled_benchmark_runner.py::run_controlled_benchmark`
crashed (`ValueError: cannot concat empty list`) whenever every intervention
condition selected zero rows for injection (e.g. a small or otherwise
degenerate evaluation split), because empty per-condition manifests were
filtered out of the list passed to `concat`, and an all-empty list crashes
`polars.concat`. Fixed by always appending each condition's (possibly
zero-row but schema-correct) manifest, so the list itself is never empty.
Covered by `tests/test_controlled_benchmark_runner.py`. Commit `d62cdd8`.

Fixing this crash also revealed that `scripts/build_defense_evidence.py`'s
committed `results/defense-evidence/v1/package_status.json` was **stale**:
it had been generated by an older script/code revision that could not
complete the controlled benchmark or the parameter-sensitivity replay
against the real target dataset. The current code already runs both
successfully. Re-running `uv run python -m scripts.build_defense_evidence
--overwrite` regenerated the package; the manuscript (T19) was corrected to
report the real confusion-matrix/F1 and Jaccard-stability numbers instead of
the previous "not executed" placeholder text.
