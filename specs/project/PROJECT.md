# Project Overview

**Project:** ATP transmission-line energization data processing
**Analyzed:** 2026-08-14

## Vision

Provide a reproducible data-processing layer for extracting, cleaning,
analyzing, and visualizing peak phase-to-ground voltages generated by ATP
statistical simulations.

## Academic boundary

The TCC covers data extraction, preprocessing, statistical validation,
probabilistic analysis, anomaly detection, and result presentation. Automated
insulation-level decisions and the company expert system are explicitly out
of scope.

## Current milestone

The repository contains an initial vertical slice with parser, P.U.
normalization, Gaussian fitting, DBSCAN/K-Means utilities, plots, and unit
tests. The next milestone is validation on representative real `.lis` data and
completion of a configurable, end-to-end reproducible run.
