# Integrations

## External data source

- ATP/ATPDraw statistical output files with `.lis` extension.
- Files are read locally using ISO-8859-1 by default.

## Runtime outputs

- Console summaries from `main.py`.
- `overvoltage_distribution.png`.
- `exceedance_probability.png`.

There is no database, web API, cloud service, or external message integration.
The current script contains a machine-specific absolute input path.
